Sobre a Biblioteca

O Sistema de Biblioteca foi desenvolvido com o objetivo de facilitar o gerenciamento e a consulta de livros.

Através do sistema, os usuários podem visualizar livros cadastrados e realizar operações de gerenciamento do acervo.

Nosso objetivo

Desenvolver uma solução simples, organizada e intuitiva para auxiliar no controle de uma biblioteca.

Tecnologias utilizadas

  • HTML5
  • CSS3
  • JavaScript
  • Git
  • GitHub
